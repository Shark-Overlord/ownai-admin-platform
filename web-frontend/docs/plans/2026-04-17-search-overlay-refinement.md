# 卡片详情弹框精修记录

## 目标

- 弹框进入后不显示可见滚动条，但保留滚动能力。
- 桌面端保持左信息右预览，左右两栏独立滚动。
- 移动端改为上预览下信息，上下两块独立滚动。
- 弹框内按钮整体改为小巧规格，避免过大的默认按钮感。
- 除右侧主视觉大标题外，弹框内所有文字控制在 `14px` 及以下。

## 布局规则

- `SearchOverlay` 外层弹框固定铺满可视区域，`DialogPrimitive.Content` 使用 `overflow-hidden`，不允许外层出现滚动条。
- 桌面端使用双栏布局：
  - 左侧为信息区。
  - 右侧为预览区。
  - 两侧各自独立 `overflow-y-auto`。
- 移动端使用上下布局：
  - 上方为预览区。
  - 下方为信息区。
  - 上下两块都必须是独立滚动容器。
- 所有滚动容器统一使用项目现有 `hide-scrollbar` 样式，隐藏滚动条轨道。

## 尺寸与排版规则

- 弹框操作按钮统一控制为紧凑尺寸，优先使用：
  - 高度 `h-8` 或 `h-9`
  - 更小的横向内边距
  - 更轻的阴影
- 以下按钮都遵循同一套紧凑规则：
  - 返回按钮
  - 外链按钮
  - 分享按钮
  - Prompt 区操作按钮
  - 分组复制按钮
- 除右侧主视觉大标题外，弹框内所有文字不超过 `14px`：
  - 左侧标题
  - Prompt 标题
  - 分组标题
  - 正文和说明文案
  - 标签和状态文案
  - 按钮文案

## 交互要求

- 点击卡片后直接打开详情弹框，不新增页面路由。
- 左右栏或上下块的滚动互不干扰。
- 复制 Prompt、复制分组内容、分享、打开原链接等交互保持可用。
- 弹框关闭后回到原卡片列表位置，不影响列表浏览状态。

## 验收标准

- 桌面端无可见滚动条，左右都能单独滚动。
- 移动端上预览下信息，无可见滚动条，上下都能单独滚动。
- 所有按钮明显比旧版更小、更紧凑。
- 除预览主视觉大标题外，其余文字不超过 `14px`。
- 构建验证通过：`npm run build`。
